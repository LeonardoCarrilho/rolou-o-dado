# 🎲 Rolou o Dado

Jogo de dados para dois jogadores feito com **HTML5, CSS3 e JavaScript puro**, manipulando o DOM.

Cada jogador rola um dado; quem tirar o maior número vence a rodada. Um placar acompanha vitórias e empates.

## Funcionalidades
- Rolagem aleatória com `Math.random()` (1 a 6)
- Troca dinâmica das imagens via `src`
- Placar de vitórias e empates, destaque para o vencedor e animação
- Layout responsivo

## Como rodar
Abra o `index.html` no navegador (ou use a extensão Live Server).

Projeto do módulo 16 do curso Full Stack Turbo (TipsCode), com o desafio de refatoração resolvido.
